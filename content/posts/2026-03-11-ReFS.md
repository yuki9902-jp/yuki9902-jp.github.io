### 1. ReFSがいつの間にか復活していた

いつの間にWindows10Proから消えてなくなっていたフォーマット規格「ReFS」がWindows11Pro 23H2で開発者ドライブ「Dev Drive」に組み込まれていました。今日、現環境で面白いこと出来ないかとGeminiと対話してて教えて貰いました。
復活していたのならと早速ReFSにフォーマットしていきます。一応制限があって、起動用のシステムドライブ、外部記憶メディアには使えません。

### 2. NTFSとReFSの比較

| Features | NTFS | ReFS |
| :---: | :---: | :---: |
| データの整合性 | 壊れても気づかない  （サイレントエラー） | チェックサムで破損を検知・報告 |
| コピー速度  （同一ドライブ内） | 物理コピー  （時間がかかる）| ブロッククローニング （0秒コピー） |
| ストレージ効率 | 実容量を消費 | クローン機能により容量を節約 |
| 修復能力 | chkdsk （数時間〜数日かかる） | オンライン修復 （OS起動中に瞬時に隔離） |


### 3. 導入後

| No | Storage Device | Disk Type | File System | Drive Letter | Uses | Discription |
|:---:| :---: | :---: | :---: | :---: | :--- | :--- | 
| 1 | NVMe  2TB | BASIC | NTFS | C: | システム   | Windowsの起動にはNTFSが必須。|
| 2 | NVMe  2TB | BASIC | ReFS | D: | AI作業     | 10GB単位のモデルの高速読込、ビルド加速を享受できる。|

| 5 | SATA  2TB | BASIC | ReFS | G: | ゲーム     | 4,5で作っていたダイナミックディスクのストライプを廃止、故障リスク半減。速さが必要なゲームをしなくなったので問題なし。 |

### 4. 設定方法

1. 「設定」 → 「システム」 → 「ストレージ」 → 「ストレージの詳細設定」 → 「ディスクとボリューム」 と開く。
2. ReFS に変更したいドライブレターの「プロパティ」を開く。
3. 「フォーマット」の「削除」をクリックしドライブを削除する。
4. 「ディスクとボリューム」に戻り、「開発者ドライブの作成」を開く。
5. 「未割り当て領域のある１ディスク」にあるディスクを選んで、「次へ」をクリックする。
6. 「ラベル」を適宜入力して「形成」をクリックする。
